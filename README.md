# Paper

This repository hosts data extracted from the scoping review together with a Quarto dashboard used for data visualisation.

The dataset (`extracted_data.csv`) includes methodological challenges, paper citation, publication year, first author, data origin, and journal information extracted from eligible papers.

The interactive dashboard is developed using Quarto (`dashboard.qmd`) and rendered to HTML (`index.html`). The rendered dashboard is published online via GitHub Pages and is available at:

https://recordscopingreview.github.io/paper/

The Quarto source file is included in this repository to support transparency, reproducibility, and future updates.
